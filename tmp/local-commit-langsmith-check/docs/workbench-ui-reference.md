# 工作台视觉参考

## 参考与取舍

- [ClarityOS / Lumière Desk](https://dribbble.com/shots/26800017-Lumi-re-Desk-ClarityOS-Minimal-Productivity-UI-Concept-Figma)：参考暖中性色背景、近白内容面、轻量状态标签，以及标题与正文的清楚层级。没有采用其侧栏或装饰图标。
- [Copilot Money](https://www.copilot.money/)：参考信息卡片中的内容分组与局部强调色。没有采用其蓝色主调和表情图标。

## 本项目中的应用

1. 最终配色以 `v2.0` 原始代码为唯一来源。载入页、首页直接沿用原来的全局颜色变量、背景渐变和状态颜色，工作台恢复原来的 `--wb-*` 调色板及图表颜色。
2. 保留当前圆润字体、标题字重、圆角、布局与信息层级；参考设计只用于结构与排版，不覆盖 `v2.0` 的配色。
3. 编号、执行状态、研究标题、摘要按阅读顺序排列。综合研判保留独立的信息区域。
4. 保留用户确认的结构：左侧四张分析卡片、右侧综合研判上下对齐，下方行情区域铺满页面宽度。
5. 没有装饰图标、表情、虚构图表或样本业务数据进入产品页面。
