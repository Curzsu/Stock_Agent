> 全量扫描日期：2026-08-08
> 扫描方式：直接读取源码、配置文件、测试与文档，对照 `README.md` 核实真实结构。

## 1. 一句话定位

FINEX 是一套 **基于 LangGraph 多智能体（Multi-Agent）架构的 A 股智能分析平台**。用户用自然语言输入一家上市公司或股票代码（例如「比亚迪」「600519」），系统会并行从 **基本面、技术面、价值面、新闻面** 四个维度调用 A 股行情/财务数据，由大模型（OpenAI 兼容 API）生成结构化分析，最后汇总成一份图文报告，并支持导出 PDF。

技术内核是一条 **`start → 4 个分析 Agent 并行 → 汇总 Agent → 结束`** 的 DAG 工作流，所有数据能力通过 **MCP（Model Context Protocol）** 统一接入。

### 3.1 backend/server.py（FastAPI，761 行）
- 提供 API：`POST /api/analyze`（启动分析）、`GET /api/status/{id}`（进度轮询）、`GET /api/result/{id}`（结果）、`GET /api/report-pdf/{id}`（下载 PDF）、`GET /api/history`（近期记录）、`GET /api/health`、`GET /api/market-kline`（上证指数 K 线）、`GET/POST /api/config` 与 `POST /api/config/test`（API Key 配置与连通性测试）。
- 用 `asyncio.create_task` 并发调度分析任务（而非 `BackgroundTasks`），保证轮询请求不被阻塞。
- 工作流总超时 `WORKFLOW_TIMEOUT_SECONDS=1200s`、Baostock 校验超时 `BAOSTOCK_TIMEOUT_SECONDS=30s`，两层兜底防止前端无限轮询卡死。
- 输入校验：公司名/代码提取、A 股首位合法性（6/0/3）、在线校验代码是否存在或退市。
- 内置 `/` 直接托管 `frontend/index.html`，`/static` 挂载前端目录。

### 3.2 agents/src — 多智能体核心
- `main.py`（CLI 入口）：ASCII 开屏 + 交互式输入，与 `server.py` **共用同一套 `build_workflow()` 工厂**，保证拓扑一致。
- `utils/workflow_builder.py`（`build_workflow()`）：构建 `start_node → 4 个 analyst → summarizer → END` 的 LangGraph 图；支持可选的 `progress_callback` 实现进度上报（Web 路径用，CLI 路径零开销）。
- `agents/`：5 个 Agent，均基于 LangChain `create_react_agent`（ReAct 模式，可自主调用 MCP 工具）：
  - `fundamental_agent.py`（346 行）基本面：财务、盈利、行业地位
  - `technical_agent.py`（297 行）技术面：价格趋势、量价、技术指标
  - `value_agent.py`（342 行）价值面：PE/PB 等估值水平
  - `news_agent.py`（333 行）新闻面：新闻情感与风险（含新闻爬虫工具）
  - `summary_agent.py`（623 行，最大）汇总：整合四路分析 → 生成最终 Markdown 报告 → 后台异步转 PDF
- `tools/`：
  - `mcp_client.py`（234 行）MCP 客户端，**进程级工具列表缓存**（失败不缓存，避免一次超时永久瘫痪）；工具对象每次被调用会自起独立 stdio 子进程，天然隔离、无串台风险。
  - `mcp_config.py`：通过 `uv run --directory mcp-server python mcp_server.py` 以 stdio 方式拉起 MCP 服务（`a_share_mcp_v2`）。
  - `openrouter_config.py`：OpenRouter/OpenAI 兼容配置。
- `utils/` 辅助模块：`state_definition.py`（AgentState TypedDict）、`stock_extractor.py`（公司名/代码提取，main 与 server 共用）、`baostock_helper.py`（线程安全单例登录 + 互斥查询，修复并发踢掉全局 session）、`llm_clients.py`、`pdf_converter.py` / `pdf_styles.py`（Markdown→PDF，投行研报风）、`execution_logger.py`（运行日志）、`log_viewer.py`、`logging_config.py`、`agent_config.py`（递归深度/超时/LLM 参数）。

### 3.3 mcp-server — A 股数据服务
- `mcp_server.py`：用 `FastMCP` 注册工具，**服务名 `a_share_data_provider`**，系统提示强调「必须用 `get_latest_trading_date()` 取真实交易日」「股价默认不复权（adjustflag=3）」。

| 模块 | 工具数 | 示例 |

| `stock_market.py` | 5 | `get_historical_k_data`、`get_stock_basic_info`、`get_dividend_data`、`get_adjust_factor_data`、`get_stock_analysis` |
| `financial_reports.py` | 9 | `get_profit_data`、`get_balance_data`、`get_cash_flow_data`、`get_dupont_data`、`get_forecast_report`… |
| `macroeconomic.py` | 7 | `get_deposit_rate_data`、`get_loan_rate_data`、`get_money_supply_data_month`、`get_shibor_data`… |
| `indices.py` | 5 | `get_sz50_stocks`、`get_hs300_stocks`、`get_zz500_stocks`、`get_all_stock` |
| `date_utils.py` | 4 | `get_current_date`、`get_latest_trading_date`、`get_market_analysis_timeframe`、`get_trade_dates` |
| `market_overview.py` | 3 | 市场概览类工具 |
| `analysis.py` | 2 | `get_stock_industry`、`get_performance_express_report` |

- 数据源抽象：`data_source_interface.py` 定义接口，`baostock_data_source.py` 实现，依赖 `baostock` 免费行情库；`formatting/markdown_formatter.py` 负责数据格式化。
- `pyproject.toml` + `uv.lock` 管理 MCP 服务自身依赖。

### 3.4 frontend/index.html（3391 行单页应用）
- 视觉：深色 + 金色（FINEX 品牌色）Glassmorphism（液态玻璃）风格，含开场动画、Blob 背景。
- 动效：GSAP（ScrollTrigger + SplitText）+ Lenis 平滑滚动，CDN 不可达时自动降级。
- 图表：lightweight-charts 渲染上证指数 K 线（`/api/market-kline`）。
- 交互：自然语言搜索 → 实时进度轮询（`/api/status`）→ 分阶段展示四路分析 → 汇总报告 → PDF 下载（带轮询可用态）。

## 4. 技术栈

| 类别 | 技术 |
|---|---|
| 后端框架 | FastAPI + Uvicorn |
| AI 编排 | LangGraph（`StateGraph` 编译 DAG）、LangChain |
| Agent 模式 | LangChain `create_react_agent`（ReAct，自主调工具） |
| 数据协议 | MCP（`langchain-mcp-adapters` + `FastMCP`） |
| 数据源 | Baostock（免费 A 股行情/财务） |
| 大模型 | OpenAI 兼容 API（OpenRouter 等，可运行时切换） |
| 报告导出 | Markdown → PDF（`xhtml2pdf`/`markdown`/`jinja2`，设计文档预留 WeasyPrint 升级路径） |
| 前端 | 原生 HTML/CSS/JS + GSAP + lightweight-charts |
| 包管理 | `uv`（MCP 服务）、`pip`/`venv`（主项目），`requirements.txt` 锁定 |

依赖要点（`requirements.txt`）：`fastapi`、`uvicorn`、`pydantic`、`langgraph>=1.1`、`langchain>=1.2`、`langchain-openai`、`langchain-mcp-adapters>=0.1.9`、`baostock`、`xhtml2pdf`、`markdown`、`jinja2`、`python-dotenv`、`uv`。

## 5. 一次分析的端到端流程

1. 前端 `POST /api/analyze {"query":"比亚迪"}` → 后端创建会话并 `asyncio.create_task` 启动工作流。
2. 提取公司名/代码，Baostock 在线校验代码存在性（带 30s 超时兜底）。
3. `build_workflow()` 编译图，`start_node` 扇出 4 个分析 Agent **并行**执行（各自用 ReAct 调 MCP 工具取数、写分析）。
4. LangGraph 的 fan-in barrier 等 4 路全部完成 → `summarizer` 汇总生成最终 Markdown 报告，并后台异步转 PDF。
5. 前端轮询 `/api/status` 展示各 Agent 进度；完成后拉取 `/api/result` 渲染报告，提供 `/api/report-pdf` 下载。

## 6. 工程亮点（从代码注释中提炼的真实设计决策）

- **共享工作流工厂**：`main.py`（CLI）与 `server.py`（Web）共用 `build_workflow()`，消除重复拓扑与「注释漂移」（曾出现过注释写 3 个 Agent 实为 4 个的问题）。
- **MCP 客户端进程级缓存 + 失败不缓存**：避免「一次超时 → 整个进程永久返回空工具」。
- **Baostock 线程安全**：进程级单例登录 + 互斥锁，解决并发请求互相踢掉全局 session 的竞态。
- **超时兜底**：工作流总超时 1200s + Baostock 校验 30s，保证 session 一定进入终态，前端不会无限轮询卡死。
- **PDF 后台非阻塞生成**：`summary_agent` 立即返回（pdf_path=None），PDF 在线程执行器异步生成；后端按 `os.path.exists` 判断可用性，前端优雅降级。
- **API Key 管理**：运行时经 `/api/config` 写 `os.environ` 即时生效 + 写 `.env` 持久化，Key 脱敏展示，`/api/config/test` 连通性自检。

## 7. 运行方式（摘自 README）

```bash
# 1. 虚拟环境
python -m venv venv && .\venv\Scripts\activate        # Windows
# 2. 依赖
pip install -r requirements.txt
# 3. 配置密钥
cp agents/.env.example agents/.env     # 填入 OPENAI_COMPATIBLE_API_KEY / BASE_URL / MODEL
# 4. 启动
scripts\start_server.bat               # 或: uvicorn backend.server:app --port 8100
# 5. 访问 http://localhost:8100
```
