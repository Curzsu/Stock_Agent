# 中科金财(002657) 综合分析报告

## 执行摘要

中科金财（sz.002657）是一家专注于金融科技解决方案和人工智能综合服务的A股上市公司。基于2026年03月30日的综合分析，公司目前处于**经营困境期**，面临持续亏损、盈利能力恶化、股价下跌等多重压力。

**核心结论：**
- **基本面**：连续多年亏损，2025年Q3亏损扩大至1.12亿元，ROE降至-6.26%，盈利能力严重不足
- **技术面**：股价从2025年高点47.17元下跌至22.31元，跌幅达52.7%，处于明显下跌趋势
- **估值面**：传统估值方法失效，市盈率为负，投资价值难以评估
- **新闻面**：AI概念热度与业绩亏损形成反差，存在概念炒作风险

**投资建议：高风险观望**
- **风险等级**：⭐⭐⭐⭐⭐（高风险）
- **预期回报**：不确定性极高，取决于公司能否扭亏为盈
- **适合投资者**：仅适合风险承受能力极强、能够承受本金大幅损失的投资者

## 公司概况

**北京中科金财科技股份有限公司**成立于2003年，2012年2月28日在深交所上市，股票代码002657。

| 项目 | 内容 |
|------|------|
| 股票代码 | sz.002657 |
| 总股本 | 3.40亿股 |
| 流通股本 | 3.35亿股 |
| 所属行业 | 软件和信息技术服务业 |
| 主营业务 | 金融科技解决方案、数据中心综合服务、人工智能综合服务 |

**核心业务布局：**
- **金融科技**：银行IT基础设施、智能风控系统、数字人民币解决方案
- **人工智能**：AI原生数据治理、硅基员工、认知数字孪生银行
- **区块链**：多方安全计算平台、FINNOSafe区块链平台
- **数字货币**：数字人民币应用、稳定币与离岸人民币清结算

**行业地位：**
作为中国金融科技智能化的先行者，公司在AI+金融领域深耕二十载，但近年来盈利能力持续下滑，行业竞争力有所减弱。

**不适合投资者：**
- 风险厌恶型投资者
- 价值投资者
- 追求稳定收益的投资者
- 长期持有型投资者

### 具体操作建议

**对于已持有投资者：**
1. 建议设置止损位：20元或17元
2. 若股价反弹至25元以上，考虑减仓
3. 密切关注季度财报，关注亏损是否收窄

**对于潜在投资者：**
1. **不建议当前入场**：基本面和技术面均不支持
2. 等待明确信号：
   - 净利润转正
   - 股价企稳并放量反弹
   - 技术指标出现金叉
3. 若参与，仓位控制在5%以内，设置严格止损
