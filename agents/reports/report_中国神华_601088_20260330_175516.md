# 中国神华(sh.601088) 综合分析报告

## 执行摘要

中国神华作为中国最大的煤炭能源企业之一，于2026年完成千亿级并购重组，进一步巩固了其煤电一体化龙头地位。综合四种分析方法，公司展现出**优秀的盈利能力、稳健的财务结构、慷慨的分红政策**，但面临行业周期性调整压力。

**投资评级：买入（长期持有）**

| 指标 | 评估 |
|------|------|
| 风险等级 | 中低风险 |
| 预期年化回报 | 8%-15%（含股息） |
| 建议持有期限 | 2年以上 |
| 适合投资者类型 | 价值投资者、长期投资者、追求稳定收益的投资者 |

**核心投资逻辑：** 千亿并购重组落地、高股息收益率（约5%）、一体化运营优势、资源储备丰富，适合作为核心防御性资产配置。

## 公司概况

**中国神华能源股份有限公司**（股票代码：sh.601088）成立于2004年，2007年10月9日在上海证券交易所上市，是中国最大的煤炭生产和销售企业之一，隶属于国家能源集团。

### 业务构成

| 业务板块 | 主要内容 | 占比 |
|---------|---------|------|
| 煤炭业务 | 煤炭开采、洗选、销售 | 核心业务 |
| 电力业务 | 燃煤发电、新能源发电 | 一体化延伸 |
| 铁路运输 | 煤炭运输铁路网络 | 配套支撑 |
| 港口航运 | 煤炭中转港口、航运 | 配套支撑 |
| 煤化工 | 煤制油、煤制烯烃等 | 产业链延伸 |

### 行业地位

- **全球最大煤炭生产商之一**：煤炭保有资源量突破684.9亿吨，可采储量达345亿吨
- **煤电一体化龙头**：形成"煤-电-运-化"完整产业链
- **国家能源安全支柱**：在国家能源战略中具有重要地位

### 最新重大事件

2026年完成**1336亿元重大并购重组**，收购国家能源集团旗下12家核心企业股权，覆盖煤炭生产、煤化工及煤炭物流等关键领域，实现资产质量"从有到优"的跃升。
