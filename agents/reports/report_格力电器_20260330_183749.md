# 格力电器(sz.000651) 综合分析报告

## 执行摘要

格力电器作为中国空调行业龙头企业，当前呈现**基本面稳健、估值极具吸引力、技术面偏弱、消息面中性偏正**的综合特征。

**核心投资逻辑：**
- **估值优势突出**：市盈率仅7倍左右，显著低于行业平均15-20倍，股息率高达7%以上
- **盈利能力强劲**：ROE维持在18-25%高水平，净利润率15%以上，现金流充沛
- **技术面承压**：股价处于中期下降趋势，从41.28元高点回落至37.88元
- **增长面临挑战**：营收增长乏力，管理层传承问题待解

**投资建议：谨慎推荐（适合价值型投资者）**

| 指标 | 评估 |
|------|------|
| 风险等级 | 中等 |
| 预期回报 | 15-30%（1-2年） |
| 投资期限 | 中长期（1-3年） |
| 适合投资者 | 稳健型、价值型、追求分红收益的投资者 |
