# 紫金矿业(sh.601899) 综合分析报告

## 执行摘要

紫金矿业作为中国领先的有色金属矿业公司，2025年业绩表现亮眼，净利润同比增长62%至518亿元，创历史新高。然而，公司股价自2026年1月高点43.45元大幅回调至当前32.78元，跌幅约24.6%，主要受金价高位回落及市场对大规模收购估值的担忧影响。

**投资评级：谨慎推荐**

| 指标 | 评估 |
|------|------|
| 风险等级 | 中等偏高 |
| 预期回报 | 中长期看涨，短期震荡 |
| 投资周期 | 建议6-12个月以上 |
| 适合投资者 | 风险承受能力较强的价值投资者 |

**核心观点：** 公司基本面强劲，盈利能力行业领先，但短期面临金价回调压力和收购整合风险。建议投资者关注金价企稳信号，在估值合理区间逢低布局。

---

## 公司概况

紫金矿业集团股份有限公司是中国最大的黄金生产企业之一，也是全球领先的有色金属矿业公司。公司主要从事金、铜、锌等有色金属的勘查、开采、选矿、冶炼及销售业务。

**核心业务：**
- 黄金开采与冶炼：矿产金产量90吨（2025年），同比增长23%
- 铜矿开采：受益于新能源转型带来的需求增长
- 锌及其他有色金属

**行业地位：**
- 中国最大的黄金生产企业
- 全球矿业巨头，资源储备丰富
- 2024年6月获纳入恒生中国企业指数

**战略布局：**
公司采取逆周期扩张战略，近年来累计并购金额超600亿元，包括收购藏格矿业、赤峰黄金、加拿大联合黄金等，大幅增加资源储备。
