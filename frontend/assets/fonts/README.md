# UI font

FINEX Round is a web-format conversion of ChillRoundF by ChillType,
licensed under the SIL Open Font License 1.1.

Source: https://github.com/Warren2060/ChillRound

The family and PostScript names were changed to FINEX Round to respect the
original reserved font name. Glyphs are unchanged. The complete original
license is included in `OFL-ChillRound.txt`.
