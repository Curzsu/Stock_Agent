FAQ

常见问题

分析的数据来源是什么？⌄
行情与财务数据来自 baostock 等公开数据源，由各智能体在分析时实时抓取，并结合公开财报与新闻信息。
分析包含哪些维度？⌄
包含基本面（财务指标、盈利能力）、技术面（价格趋势、交易量）、估值（市盈率、内在价值）和新闻舆情四个维度，并汇总为综合研判。
如何使用本系统？⌄
在首页输入公司名称或股票代码，点击「分析」即可。无需注册，配置好 API Key 后即可使用多智能体分析能力。
分析需要多长时间？⌄
通常几十秒内完成。后台采用并行智能体，分析页会实时展示各环节进度。
